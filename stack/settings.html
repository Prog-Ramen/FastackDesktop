Keyboard activity tracking

While clocked in, Fastack samples system idle time and scrolling. Optionally, an isolated native worker counts keystrokes system-wide, with in-app counting as a safe fallback. The productivity report then distinguishes writing (typing) from reading (scrolling). Requires Accessibility permission on macOS. A worker failure cannot crash Fastack. Default is off — key values, window titles, app names, screenshots, and typed content are never captured.
